# Testing Overview

## Overview

This document outlines the testing strategies and practices employed in the **MyPets** application.

## Unit Testing
- The application employs unit testing to ensure each component functions as expected.
- **Location of Tests**: All tests reside in the **test/** directory.
- Use the Flutter testing framework to write your tests.

## Running Tests
- Execute tests with the following command:
  ```bash
  flutter test
  ```
- To run a specific test file:
  ```bash
  flutter test path/to/test_file.dart
  ```

## Test Coverage
- Utilize `flutter test --coverage` to check for test coverage across your codebase.
- It is crucial to maintain high test coverage for critical functionalities.
